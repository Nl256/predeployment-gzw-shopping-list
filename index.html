03 OBS connection & backups +

OBS is optional. Your output saves locally without connecting.

  1. Choose Connect OBS to create a separate overlay for this tab. This sends a copy of this tab’s content, images and font online.
  2. Add a Browser Source in OBS / Streamlabs. Leave Local file unchecked.
  3. Paste
  4. Set width to 600 and height to 1080. Use these suggested dimensions when changing layouts; existing sources also scale the overlay to fit.
  5. Keep this control page open while editing. OBS updates automatically when online.

Add a separate Browser Source for each tab’s OBS URL. All sources can be live together; the editor tab you select does not control which source OBS displays. Each browser keeps its own tabs and saves. Share the regular website address with friends. Keep your OBS URL private; it gives read-only access to your overlay and its assets. Disconnecting revokes that URL and removes its online copy.

Each backup includes the selected tab’s content, reward images, colors and imported font, without OBS access keys. Export tabs separately. Create a tab and import its backup to move it to another browser or device. Importing replaces only the selected tab; Undo can restore it. Local saves belong to the browser profile, so people sharing one browser profile share its save.
